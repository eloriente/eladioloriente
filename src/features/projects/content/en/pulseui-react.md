A React component library designed to be used as-is, adapted, or used as the foundation for your own design system.

- 30+ components: forms, tables, modals, menus, notifications, navigation and more.
- Accessible by default: every interactive component follows its ARIA pattern, and Storybook fails the build on any accessibility violation.
- Design tokens (`--pulse-*`) to adapt colors, typography and spacing, also exportable to Figma.
- Tailwind CSS compatible: every component accepts `className`.
- Ships an MCP server so AI assistants can look up props and examples instead of guessing.
- Interactive Storybook docs and real-browser tests with Vitest and Playwright.
