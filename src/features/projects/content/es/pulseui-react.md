Librería de componentes para React pensada para usarse tal cual, adaptarse o servir de base para un sistema de diseño propio.

- Más de 30 componentes: formularios, tablas, modales, menús, notificaciones, navegación y más.
- Accesible por defecto: cada componente interactivo sigue su patrón ARIA y Storybook bloquea la build ante cualquier fallo de accesibilidad.
- Design tokens (`--pulse-*`) para adaptar colores, tipografía y espaciado, también exportables a Figma.
- Compatible con Tailwind CSS: todos los componentes aceptan `className`.
- Incluye un servidor MCP para que los asistentes de IA consulten props y ejemplos sin inventárselos.
- Documentación interactiva en Storybook y tests en navegador real con Vitest y Playwright.
